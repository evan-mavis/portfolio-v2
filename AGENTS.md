# AGENTS.md

Personal portfolio site for Evan Mavis. Next.js 16 (App Router), React 19, TypeScript (strict), Tailwind CSS 4, shadcn/ui. Deployed to Vercel on every push to `main`.

## Setup

- Node.js 24 (see `.nvmrc`). Use **npm**; `package-lock.json` is the source of truth.
- `npm install && npm run dev` then open http://localhost:3000.
- No environment variables are required locally. See `.env.example` for optional ones.
- No database, auth, or external services are needed to run the site.

## Commands

| Task                      | Command                                                         |

| Dev server                | `npm run dev`                                                   |
| Production build          | `npm run build` then `npm run start`                            |

The pre-commit hook (Husky) runs a file-size check, Prettier + ESLint on staged files, and the type check. Do not bypass it with `--no-verify`.

## Layout

- `app/`: routes. `/` (portfolio tree), `/travel`, `/food`, `/api/health`.
- `components/`: app components. `components/ui/` is generated by shadcn; edit sparingly.
- `lib/`: helpers (`cn`, `getTechIcon`).
- `public/`: images and the resume PDF. Keep new images under 5 MB (enforced by the hook).
- `e2e/`: Playwright specs. Unit tests live next to source files.
- `docs/`: architecture and runbook.

## Conventions

- **Naming** (enforced by `@typescript-eslint/naming-convention`): camelCase for variables and functions, PascalCase for components, types, and interfaces, UPPER_CASE for module constants. Component files are PascalCase (`PageLayout.tsx`); other files are kebab-case (`tech-icons.tsx`).
- **Tests**: unit tests are named `*.test.ts(x)` next to the file under test; e2e specs are `e2e/*.spec.ts`. New components need tests; keep coverage above the thresholds in `vitest.config.mts`.
- **Complexity**: ESLint enforces `complexity <= 15`, `max-depth <= 4`, and `max-lines <= 700`. Split components instead of raising limits.
- **Tech debt**: do not leave bare `TODO`/`FIXME` comments (ESLint warns). Open a GitHub issue and reference it, for example `// See #12`.
- **Analytics**: user-facing links fire `track("<thing>_click")` from `@vercel/analytics`. Keep event names snake_case. Never send personal data in event properties.
- **Client components**: add `"use client"` only where hooks or browser APIs are needed.

## Interactive QA

1. `npm install && npm run dev`.
2. `curl -s localhost:3000/api/health` should return `{"status":"ok",...}`.
3. Open http://localhost:3000. The file tree animates in, with `evan mavis/` and the job title expanded.
4. Click the expand toggle (top right). All folders open. Click the theme toggle and confirm light and dark modes switch.
5. Click `interesting stuff/ → travel`. The travel gallery loads. Click **Back** to return.
6. There is no login. All pages are public.

`npm run test:e2e` automates steps 2 to 5.
